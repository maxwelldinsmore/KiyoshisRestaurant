# 🏮 Sushi Bai Kiyoshi  Restaurant Management System

A full‑stack restaurant management system designed for **Sushi Bai Kiyoshi**, a high‑volume Japanese takeout restaurant that relies on precision, freshness, and speed.

This project streamlines daily operations from **smart ordering** to **inventory freshness tracking**, **loyalty rewards**, and **real‑time insights**  all while preserving the simplicity of Mr. Kiyoshi’s workflow.

---

## 🍣 About the Project

Sushi Bai Kiyoshi operates in a fast‑paced environment where timing and freshness matter.  
Our system replaces manual notebooks and memory‑based processes with a centralized, reliable platform that supports:

- Online & walk‑in ordering  
- Inventory tracking by weight & quantity  
- Freshness monitoring (Day‑1 / Day‑2)  
- Sales insights & reporting  
- Visit‑based loyalty rewards  
- Real‑time SMS/email updates  

Built with a fully normalized **3NF relational database**, this system ensures accuracy, scalability, and smooth day‑to‑day operations.
